### 🤖 BerichtsAI

BerichtsAI is an Android application focused on creating vocational training reports with the help of AI.

The goal is to make creating weekly reports faster and easier while keeping the application simple to use.

#### ✨ Features & Concepts

- 🤖 AI-assisted report generation
- 🎤 Speech input
- 📅 Automatic weekly reports
- 🧠 Local AI / LLM support
- 📦 Downloadable AI models
- 📱 Modern Android interface
- ✨ Smooth animations
- 🌙 Dark Mode
- ⚙️ CPU / RAM configuration
- 🧠 NPU support
- 💾 Local data processing
- 🔒 Privacy-focused architecture

The application is designed around modern Android design principles with a strong focus on local processing and performance.
